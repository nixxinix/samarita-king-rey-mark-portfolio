## About

I'm a curious developer based in Pasay City, Philippines, with two years of experience across web development, data, and electronics. I enjoy solving problems and building useful projects, from websites and data tools to connected devices.

This portfolio collects the projects I've worked on, the tools and skills I've developed, and the things I've learned along the way.

## Features

- **Home:** hero, skills, tools, and certifications with a carousel and lightbox.
- **Projects:** project cards with filters, plus project pages with key facts and next/previous navigation.
- **Contact:** contact form and contact details.
- Responsive layout with a side menu, scroll reveal effects, and a back-to-top button.
- Content lives in data files (`src/data/`), so projects, certifications, and site details can be updated without touching components.

## Tech Stack

| Layer | Technology |
|---|---|
| UI | React, React Router |
| Build | Vite |
| Fonts | IBM Plex Mono (Fontsource) |
| Quality | ESLint |
| Hosting | Vercel (SPA rewrites and security headers in `vercel.json`) |

## Project Structure

```text
src/
├── components/
│   ├── home/        # Hero, projects, skills, tools, certifications
│   ├── project/     # Project facts and pager
│   ├── contact/     # Contact form and info
│   ├── layout/      # Header, footer, side menu, route effects
│   └── ui/          # Buttons, icons, banners, reveal animations
└── data/            # projects, certifications, navigation, site details
```

## Getting Started

**Prerequisites:** Node.js (version in `.nvmrc`) and npm.

```bash
git clone https://github.com/nixxinix/samarita-king-rey-mark-portfolio.git
cd samarita-king-rey-mark-portfolio
npm install
cp .env.example .env
npm run dev
```

| Command | What it does |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Build for production into `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Lint the code |
